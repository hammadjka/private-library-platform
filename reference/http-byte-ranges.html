Response headers

HTTP/1.1 206 Partial Content
Content-Length: 5
Content-Range: bytes 6-10/11
Accept-Ranges: bytes

6-10 is the selected inclusive interval; 11 is the complete representation length.

HTTP/1.1 416 Range Not Satisfiable
Content-Length: 0
Content-Range: bytes */11
Accept-Ranges: bytes

The asterisk means no interval was selected; 11 still tells the client the current complete length.
